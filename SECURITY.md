# Security Policy

Please **do not open public issues for active vulnerabilities** or include live tokens in reports.

Until a dedicated private advisory channel is published, contact the repository maintainer privately through their GitHub profile, or use GitHub's *Report a vulnerability* feature once it has been enabled.

SafePush runs locally and does not phone home. It does **not** validate discovered credentials or scan Git history. False negatives are possible and expected. Do not rely on this as the only protection for sensitive credentials.
